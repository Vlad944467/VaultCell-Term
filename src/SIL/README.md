# SIL — Simple Interpreted Language

**SIL** — это встроенный, низкоуровневый, императивный, процедурный язык программирования, написанный на C.

---

## 🚀 Как запустить программу на SIL

1. Создайте файл `programm.siv` с кодом на SIL
2. Запустите `VaultCell-Term`
3. Напишите `9` (SIL интерпретатор)
4. Напишите `2` (запуск файла)
5. Напишите `1` (подтверждение)
6. Вы увидите результат программы
